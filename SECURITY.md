# Segurança

Encontrou uma vulnerabilidade? Reporte de forma privada pela aba **Security → Report a vulnerability** deste
repositório, em vez de abrir uma issue pública. Respondemos assim que possível.

O app não guarda respostas nem dados pessoais: as respostas ficam no navegador e o link do resultado contém só a posição
em cada eixo (ver /sobre). Problemas de conteúdo (fato errado, fonte quebrada, posição mal estimada) podem ir em issues
normais.
